# Проверка ChatGPT Web

Отдельный исследовательский macOS-прототип, не интеграция в основной островок.

Сборка: `bash Checks/ChatGPTWeb/build.sh`. Результат: `/private/tmp/notch-chatgpt-probe/ChatGPTProbe.app`. Сборка размещается вне Documents: iCloud повторно добавляет к .app метаданные, нарушающие проверку подписи. Временную сборку можно восстановить этой командой.

Обычный WKWebView открывает https://chatgpt.com. У каждого пользователя собственное постоянное хранилище WebKit под идентификатором приложения. Профиль не входит в .app и не копируется из Safari/Chrome. Нет API-ключа, чтения cookies, DOM-инъекций, скрытой отправки вопросов или импорта чужих сессий. «Сброс входа» очищает данные сайтов прототипа после подтверждения; это ещё нужно проверить после реальной авторизации.

Кнопка «Размер» переключает содержимое окна 900 × 700 / 405 × 240. Тестовые кнопки занимают часть высоты; это не окончательная компоновка островка. «В браузере» открывает текущую HTTPS-ссылку ChatGPT в обычном браузере, где нужен вход в тот же аккаунт. «Новый чат» открывает главную сайта. Временные чаты не подходят для проверки общей истории.

## Подтверждено 15 октября 2026

- Swift-компиляция отдельного прототипа прошла.
- Прототип запущен; сайт ChatGPT реально загрузился в WKWebView, видны Log in и поле сообщения.
- Автоматическое управление кнопками через CUA заблокировано ошибкой изменившегося состояния приложения; это не доказательство неисправности кнопок.

## Ручная проверка перед выбором архитектуры

1. Войти своим обычным способом (email/Google/Apple/Microsoft). Не передавать пароль разработчику или в чат. Убедиться, что форма входа принадлежит ожидаемому сервису.
2. Создать обычный, не временный разговор с безличным текстом. Открыть его через «В браузере» под тем же аккаунтом и убедиться в совпадении сообщений.
3. Ответить в браузере и обновить прототип; проверить обратное направление.
4. Закрыть/открыть прототип: проверить сохранение входа. Проверить сброс входа и смену аккаунта, не затрагивая браузер.
5. Переключить размер и оценить ввод, прокрутку и ответ; проверить вложение несекретного тестового файла через системный выбор.
6. Проверить отсутствие сети и восстановление; повторить на другом Mac/аккаунте.

Вход и синхронизация пока не подтверждены. Доступность сайта не гарантирует поддержку всех провайдеров входа во встроенном браузере. Публикация требует отдельной проверки условий сервиса, подписи и notarization. Локальная ad-hoc подпись предназначена для разработки.
